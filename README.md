# TF2 Casual Badges

Every Team Fortress 2 casual rank badge: all 8 tiers × 150 levels (1200 images).

Each image is a 256×256 transparent PNG with the badge centered, rendered straight from the game's badge model.

## Structure

```
casual/prestige_TIER/level_TIER_LEVEL.png
```

Example: `casual/prestige_3/level_3_042.png` is tier 3, level 42.

## Why

I couldn't find a complete, clean, reliable set of these anywhere, so I exported them myself and am sharing them here in case they're useful to anyone else.
